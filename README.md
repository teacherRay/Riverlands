# Riverlands

Riverlands is a relaxing low-poly 3D island simulation/world-building
experiment built in Godot.

The project explores how far an AI coding agent can develop a coherent
3D game world from a concept image, a project specification, and access
to Godot through MCP.

## Origin

Riverlands began on 24 September 2026 with a concept image and the prompt:

> Use the Riverlands 3.png image file as a guide and follow instructions.md
> to create Riverlands, a relaxing low-poly 3D simulation/world-building
> game set on a large fictional island.

Gemini 3.7 Flash High then created the initial playable island in
approximately 40 minutes.

## Initial World

The first version includes:

- Large low-poly island
- Central freshwater lake
- Mountains and forests
- Farms and livestock
- Coastal settlements
- Railway network
- Roads
- Viaducts
- Windmills and watermills
- Lighthouse and harbour areas
- Wildlife including ducks
- Day/night cycle
- Camera navigation and landmark views

## Project Direction

Riverlands is intended to grow into a living island economy with
specialised towns, agriculture, forestry, fishing, railways, road
transport, shipping, wildlife and tourism.

Future production chains may include:

Wheat → Mill → Flour → Bakery → Market/Inn

Barley → Brewery → Riverlands Beer → Inn

Forest → Sawmill → Timber → Towns

Fish → Wharf → Market/Inn

Livestock → Meat/Dairy → Towns
